# 🎲 Valorant Swiftplay Randomizer

Link do Randomizer: https://franthescod.github.io/Valorant_Randomizer/

Um gerador aleatório de **Agentes** e **Armas** feito sob medida para o modo **Frenético (Swiftplay)** do Valorant. Adicione um desafio extra às suas partidas com composições e armamentos totalmente Aleatórios.

---

## 🚀 Funcionalidades

* **Sorteio de Agentes:** Seleção aleatória de qualquer agente do jogo.
* **Sorteio de Armas:** Gerador de armas baseado na economia das rodadas.
* **Foco no Modo Frenético:** Foi pensando na economia e rodadas do Frenético.
* **Linguagem:** HTML / CSS / JavaScript

---
## 📦 Como Funciona o Randomizer

* O **dado** ao lado do agente gera um agente e 4 armas.
* O **dado** ao lado da ultima arma gera 4 armas novas.
* A **engrenagem** serve para você adiconar ou remover armas em alguma rodada específica, por exemplo, adicionar a Operator na rodada 4.
* Além disso ela tambem deixa você remover algum **agente** especifico.
* Se clicar em uma arma, você a **bloqueia** a deixando de fora de qualquer novo sorteio, util caso caia operator e você fique sem grana.
